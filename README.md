# Караоке-веб-приложение

Мини-проект для воспроизведения музыки с синхронизированными текстами (караоке). 

Приложение написано на классическом MVC с использованием связки PHP и Python. Поиск треков, скачивание аудио и текстов происходит через неофициальное API Яндекс Музыки, а также открытую базу LRCLIB.

## Стек технологий

* Backend: PHP 8.2 (CodeIgniter 4)
* База данных: MariaDB 10.6
* Микросервис поиска и загрузки: Python (Flask, yandex-music)
* Frontend: HTML, CSS, JavaScript
* Контейнеризация: Docker, Docker Compose

Интеграция с Яндекс Музыкой реализована на основе библиотеки [yandex-music-api](https://github.com/MarshalX/yandex-music-api).

## Как развернуть проект

1. Установите Docker и Docker Compose на ваш компьютер.
2. Клонируйте репозиторий и перейдите в папку проекта.
3. Откройте файл `downloader.py` и вставьте ваш OAuth-токен от Яндекс Музыки в переменную `TOKEN`.
4. В файле `.env` укажите параметры подключения к базе данных (хост: `db`, имя базы: `karaoke`, пароль: `1234`).
5. Запустите сборку и контейнеры командой:

```bash
sudo docker-compose up -d --build

После завершения сборки приложение будет доступно по адресу http://localhost:8080.
